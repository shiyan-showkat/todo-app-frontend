# 🎨 Todo App Frontend

A modern and responsive **Todo Application UI** built using **React (Vite)** and **Tailwind CSS**, connected to a Node.js backend API.

---

## 🔥 Features

- ➕ Add new todos
- ✏️ Edit existing todos
- 🗑️ Delete todos
- 📋 Display all todos
- 🔄 Real-time UI updates
- 🚫 Prevent empty input
- 🎨 Glassmorphism + modern UI
- ⚡ Smooth user experience

---

## 🛠️ Tech Stack

- React (Vite)
- Tailwind CSS
- JavaScript (ES6)
- Fetch API

## ⚙️ How It Works

1. User enters a todo in input field
2. Frontend sends request to backend (POST)
3. Backend stores data in MongoDB
4. Frontend fetches todos (GET)
5. Todos are displayed using `map()`
6. Edit updates todo using PUT API
7. Delete removes todo using DELETE API

---

## 🧠 Key Concepts Used

- useState (state management)
- useEffect (API calls)
- map() for rendering lists
- filter() for deleting items
- conditional rendering (Add/Update button)
